# SWbongo

SWbongoは、キーボードやXInput対応アーケードコントローラーの入力に合わせてキャラクターが動く、OBSブラウザソース向けのオーバーレイです。

## 必要なもの

- Windows 10またはWindows 11
- OBS Studio
- Python 3
- .NET 10 SDK
- 正規に配布されたキャラクター用 `.pak`
- コントローラーを使用する場合はXInput対応機器

## 1. キャラクターを配置する

リポジトリ直下に次のフォルダーを作成します。

```text
assets/characters/
```

正規に配布された `.pak` をこのフォルダーへ入れてください。複数の `.pak` を同時に配置できます。拡張子を除いたファイル名が、表示キャラクターの選択欄に表示されます。

## 2. 表示キャラクターと入力を設定する

`start-key-config.bat` をダブルクリックします。

### キャラクターの選択

1. 画面右上のキャラクター選択欄を開きます。
2. 表示したいキャラクターを選択します。
3. 「保存」を押します。

設定画面を開いたまま新しい `.pak` を追加した場合も、選択欄を開き直すと再検出されます。

### キーボードの設定

1. 「キーボード」タブを開きます。
2. 変更したいレバー方向またはボタンの割り当て欄を押します。
3. 割り当てたいキーを押します。
4. すべて設定したら「保存」を押します。

入力待ちを中止する場合は `Esc`、割り当てを解除する場合は `Delete` または `Backspace` を押します。同じキーを別の項目へ割り当てると、以前の項目からは自動的に解除されます。

### アケコン／コントローラーの設定

1. XInput対応コントローラーを接続します。
2. 「アケコン / コントローラー」タブを開きます。
3. 変更したい項目の割り当て欄を押します。
4. 登録したいレバー方向を入力するか、ボタンを押します。
5. すべて設定したら「保存」を押します。

十字キー、左右スティックの軸、ボタン、トリガーを登録できます。

### 初期設定

| 操作 | キーボード |
|---|---|
| レバー上 | `↑` / `W` |
| レバー下 | `↓` / `S` |
| レバー左 | `←` / `A` |
| レバー右 | `→` / `D` |
| 上段ボタン1～4 | `U` / `I` / `O` / `P` |
| 下段ボタン1～4 | `J` / `K` / `L` / `;` |

設定はリポジトリ直下の `config.ini` に保存されます。「再読み込み」で保存済み設定を読み直し、「初期設定に戻す」で上記の設定へ戻せます。

## 3. 表示サーバーを起動する

`start-obs-input.bat` をダブルクリックします。

次のURLが表示されたら起動完了です。

```text
http://127.0.0.1:8895/
```

OBSで使用している間はサーバーのウィンドウを閉じないでください。ブラウザーで動作確認する場合も同じURLを開きます。`index.html` を直接開く方式には対応していません。

## 4. OBSへ追加する

OBSで「ブラウザ」ソースを追加し、次のように設定します。

| 項目 | 設定値 |
|---|---|
| ローカルファイル | オフ |
| URL | `http://127.0.0.1:8895/` |
| 幅 | `1514` |
| 高さ | `1514` |

設定後、キーやコントローラーを入力してキャラクターが反応することを確認してください。キャラクターや入力設定を保存した場合は、起動中の表示にも自動的に反映されます。

## 5. 新しいキャラクターを追加する

1. 正規に配布された新しい `.pak` を `assets/characters/` へ入れます。
2. 入力設定画面のキャラクター選択欄を開きます。
3. 追加されたファイル名のキャラクターを選びます。
4. 「保存」を押します。

`.pak` の追加だけで利用でき、ソースコードやEXEを作り直す必要はありません。破損したファイルや対応形式ではないファイルは表示できません。

## 6. 反応しない場合

1. `start-obs-input.bat` のウィンドウが開いているか確認します。
2. OBSのURLが `http://127.0.0.1:8895/` になっているか確認します。
3. `assets/characters/` に正規の `.pak` が入っているか確認します。
4. `config.ini` を保存したか確認します。
5. OBSブラウザソースの「現在のページのキャッシュを更新」を実行します。
6. コントローラーを使用する場合はXInputモードになっているか確認します。
7. 8895番ポートを使用する古いサーバーが残っている場合は終了し、再起動します。

## 終了方法

表示サーバーのウィンドウで `Ctrl+C` を押すか、ウィンドウを閉じます。
