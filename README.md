# SWbongo

OBSブラウザソース向けの、キーボード・XInput対応アーケード表示プロジェクトです。

## 起動

OBSでも通常ブラウザでも `start-obs-input.bat` を起動し、`http://127.0.0.1:8895/` を開きます。素材は暗号化パッケージから配信するため、`index.html` の直接表示には対応しません。

- レバー: `WASD`、方向キー、ゲームパッドの十字キー／左スティック
- ボタン: 上段 `U I O P`、下段 `J K L ;`
- 表示・入力設定: `start-key-config.bat` でWPF設定アプリを起動し、検出されたキャラクターと入力割り当てを選択
- キーボード設定: レバー4方向と8ボタン
- アケコン設定: 接続したXInput機器のレバー方向・ボタンを実入力で検出して割り当て
- 設定ファイル: `keybindings.ini`。WPFから保存・再読み込み可能
- 素材内の `#00FF00` は入力サーバーがメモリ上で透明化して配信
- 標準表示は以前と同じ正方形比率を維持。ブラウザ領域いっぱいへ広げる場合はURLへ `?fit=fill` を追加
- デバッグ表示: URL末尾へ `?debug=1` を追加

## 描画方式

方向別画像は使いません。暗号化パッケージ内の `handsLiver.png` 一枚をCanvasで描画します。新素材の右レバー・左8ボタン配置に合わせて、支点とボタン座標を再測定しています。

レバー根元 `(868.5, 1316)` を固定し、入力ベクトル `(x, y)` を3D上の傾きへ変換してから画面座標へ投影します。純粋な前後入力は、GIMPの3D変換と同じ考え方で、レバー全体を一枚の平面として射影変形します。比較用の `handsLiverGo.png` と `handsLiverBack.png` は変形行列の計測にだけ使用し、実行時には読み込みません。軸と手付きノブを分離しないため接合部が折れず、前は画面左へ短く、後ろは画面右へ長く倒れます。左右・斜め入力は従来の投影を維持し、アナログの倒し量にも連続対応します。

## 素材パッケージ

- 実行用素材はキャラクターごとの `.pak` として `assets/characters/` に配置します。
- 正規の `.pak` は自動検出され、拡張子を除いたファイル名が設定画面へ表示されます。
- `.pak` 全体をアプリ専用形式で暗号化しており、元PNGを置かずに読み込めます。
- 入力サーバーは素材をメモリ上で復号し、`/media/...` の仮想URLから表示します。PNGファイルを実行フォルダーへ展開しません。
- 配布用EXEに復号処理を含めるため、配布先のWindows PCでもそのまま使用できます。
- これは保存状態の素材を直接再利用しにくくする対策です。画面キャプチャなど、表示後の完全なコピー防止まではできません。

必要な7枚のPNGから `.pak` を作成する場合:

```powershell
python -B build_asset_pak.py --source-dir "素材フォルダー" --output "assets\characters\character-name.pak"
```
